三项赛事，三种打法

iCAN · 创新创业

做一个能演示的原创产品，讲清它解决了什么问题

评审看三件事：是不是你原创的、有没有真的做出来、能不能说清应用场景。 创新赛道不要求商业闭环，但必须有能演示、能操作的作品；创业赛道则要求团队已经用这个项目注册了公司。

参赛形式
2–5 人团队，指导老师 ≤2
赛道
创新 / 创业 / 挑战
核心产出
可演示的产品或系统
2026 节点
4–8 月报名，11 月总决赛

有哪些赛道与方向

  • 创新赛道原创作品赛，按十个应用方向选题
  • 创业赛道已注册公司的项目，比商业化能力
  • 挑战赛道企业命题，AI、机器人、6G、电子信息等
  • 十个方向智慧建造 / 农业 / 社区 / 生活 / 医疗 / 教育 / 制造 / 软件 / 交通 / 材料

选手最后要交出什么

  • 创新赛道可演示操作的产品或系统 + 详细产品说明书
  • 创业赛道商业计划书 + 已注册公司的主体材料
  • 挑战赛道项目设计报告 PDF + 答辩 PPT，可加演示视频
  • 现场展台演示 + 答辩，总决赛同期设创新作品展
具体到一场比赛

2026 年挑战赛道的「6G+X 前沿转化挑战赛」：围绕 6G 新空口、通感算一体、内生智能等方向， 在低空经济、集成电路、智能制造里找真实需求，最终交技术方案、系统设计或软硬件原型。 比的不是论文写得多好，而是方案能不能落地验证。

RAICOM · 机器人开发

让机器人在真实场地里，把任务完整干完

赛题都带场地和道具，比的是导航、识别、抓取、对抗这些具体动作能不能稳定复现。 现场调试时间有限，参数没调好就是跑不动——纸面方案在这里拿不到分。

参赛形式
1–3 名学生 + 1–2 名老师
赛道
CAIM / CAIA / CAIP / CAIR
核心产出
可现场运行的机器人整机
赛制
省赛晋级全国总决赛

四大赛道，代表赛题

  • CAIR 强体轮式-火星科考 / 夺宝奇兵 / 慧眼识果；足式-多模态巡检；空中-飞行协同；人形-具身智能场景
  • CAIA 设计机器人创新设计：智居环境、交互设计、演艺设计、造型设计、商业应用
  • CAIM 工创工程创新与制造方向赛题
  • CAIP 强脑智能算法与脑机方向赛题，具体以官网赛项页为准

选手最后要交出什么

  • 现场成绩机器人在指定场地连续完成任务的用时与完成率
  • 作品可运行的整机或软件系统 + 技术方案
  • 答辩设计思路、技术难点与现场演示
  • 报名限制全日制在校生（中职/高职/本科/硕博），每人限报 1 项赛题
具体到一场比赛

以 CAIR 强体赛道的「轮式机器人-火星科考」为例：机器人在模拟火星地表自主巡线， 识别采样点并完成物资搬运，比的是自主导航精度与任务完成率； 同赛道的「慧眼识果」则要求识别成熟果实并完成采摘动作，撞杆、超时都会直接影响成绩。

RST · 机器人与仿真

要么造一台水下机器人，要么写一套能赢的策略

中国仿真学会主办，已办到第十九届。智慧海洋赛道要把实体水下机器人放进水池完成任务； 仿真技术赛道和个人赛则在软件里跑，写 Python 控制仿真机器鱼。成绩就是用时、进球和任务完成度。

参赛形式
团队赛 + 个人赛
赛道
5 条，40+ 个组别
核心产出
机器人整机或策略代码
赛制
校赛 → 省赛 → 国赛

五大赛道，组别举例

  • 智慧海洋12 组：全局视觉、水下操控、自主视觉、水面机器人、水下工程作业等
  • 仿真技术6 组：太空目标监测识别仿真、集群智能算法、工程仿真等
  • 智能制造10 组：机器人格斗与仿真、人形机器人、无人机、无人车等
  • 创新创业7 组：创新创意、创业、前沿技术挑战等
  • 个人赛6 组：水中机器鱼仿真、轮式足球仿真、DeepSeek 专项等

选手最后要交出什么

  • 实体组水下 / 水面机器人整机，现场下水完成任务
  • 仿真组策略代码或仿真模型，在赛事官网提交
  • 个人赛1 人独立完成，指导老师不超过 2 人
  • 硬件门槛水中机器鱼仿真组：Windows 10 + i5 + GTX1050 即可，无需买实体鱼
具体到一场比赛

个人赛「水中机器鱼仿真组（第三赛季）」设两个科目： ① 障碍竞速——60 秒内控制一条仿真鱼绕过并环绕 3 个障碍到达终点，按用时排名； ② 水球 2V2——控制己方两条鱼，2 分钟内把水球打进对方球门，进球多者获胜。 选手只需在官网提交策略文件，平台加载后自动跑完比赛。

关于这个站点

这是一个由学生团队维护的竞赛宣传页，不是赛事官方站点。我们只把赛项内容、战报和入口整理清楚，不代办报名。

我们在做什么

三项赛事经常被放在一起宣传，但很多同学看完还是不知道它们分别比什么。 所以我们把官网通知、赛项规则和高校公开战报对照着读，压成现在这一版： 每项赛事有哪些赛道、选手要交出什么、一个赛项具体怎么打。

战报都标注了来源，成绩表述以原报道为准；赛项与赛程以赛事官网最新通知为准。 若你发现信息有误，或希望补充自己学校的报道，欢迎通过学院或社团渠道联系我们。
